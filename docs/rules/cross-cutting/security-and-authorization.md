# 安全与鉴权（横切规范）

> 本文件是跨栈规则。`stack/backend.md`、`stack/frontend.md` **不再重复**本文件内容，只保留链接指向。

## 1. 安全规范

前端表单校验不能作为安全防线。
后端鉴权才是最终安全保障。

严禁出现以下行为：

- 泄露密钥机密
- 绕过鉴权校验
- 关闭安全检查
- 信任客户端传递过来的权限
- 暴露内部错误详情
- 打印日志输出凭证、令牌

## 2. 身份认证

认证用于确认请求方身份。
**绝不可以认为完成身份认证就等同于拥有操作权限**。

## 3. 权限鉴权

权限校验必须在后端强制执行。
校验维度参考：

- 角色
- 权限点
- 资源归属关系
- 租户数据边界
- 业务操作专属权限

前端权限判断仅作用户体验优化，不能作为安全依据。
