# 面向失败的设计（横切规范）

> 本文件是跨栈规则。`stack/backend.md`、`stack/frontend.md` **不再重复**本文件内容，只保留链接指向。

## 1. 生产环境思维

开发时必须默认考虑如下现实场景：

- 存在线上业务流量
- 存在线上真实业务数据
- 多用户会并发操作
- 请求可能被重复触发
- 请求可能被重试
- 请求可能超时
- 请求可能失败
- 响应返回顺序可能错乱
- 用户会双击按钮
- 用户操作过程中刷新页面
- 浏览器标签页长期驻留后台
- 浏览器标签页被复制多开
- 网络连接可能中断
- 用户认证会话可能过期
- Redis 服务可能不可用
- 数据库会出现锁竞争 / 资源争抢
- 部署过程中仍有活跃用户请求
- 部署期间新旧版本应用会同时并存

**不能只按照理想正常流程设计代码，必须处理各类异常分支。**

## 2. Redis 边界

Redis 的用途必须明确定义。
可用场景：

- 缓存
- 临时状态
- 限流
- 分布式协同
- 分布式锁

Redis**不能天然作为权威数据源**。
