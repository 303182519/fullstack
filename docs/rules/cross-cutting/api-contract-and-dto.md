# API 契约与 DTO（横切规范）

> 本文件是跨栈规则。`stack/backend.md`、`stack/frontend.md` **不再重复**本文件内容，只保留链接指向。

## 1. API 接口边界

前后端通过明确的接口契约通信。
前端代码禁止直接耦合：

- Prisma 模型
- 数据库实现细节
- 后端内部模块
- 数据库字段名
- 后端内部异常结构

传输 DTO（接口传输对象）和持久化数据库模型职责不同，二者不能混为一谈。

## 2. 数据传输对象（DTO）

DTO 用于定义接口传输层的数据边界。
⚠️ 不要默认 DTO 和 Prisma 数据库模型完全等同。
执行业务逻辑前，必须对外部传入数据做校验。
