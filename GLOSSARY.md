# GLOSSARY

本仓库领域术语表。只收录领域概念，不收录实现细节。术语在代码、文档与 ADR 中的用法以本表为准。

## 多租户

| 术语       | 英文           | 定义                                                                                                                        |
| ---------- | -------------- | --------------------------------------------------------------------------------------------------------------------------- |
| 多租户     | Multi-Tenancy  | 同一系统实例服务多个互不可见的组织，数据隔离是系统级约束而非业务功能。                                                      |
| 租户       | Tenant         | 接入平台的一个独立组织或客户，是数据归属与隔离的基本单位。                                                                  |
| 平台       | Platform       | 运营方自身。平台级数据（如租户列表、套餐定义）不属于任何租户。                                                              |
| 租户套餐   | Tenant Package | 一个租户可用功能范围（菜单与权限集合）的打包配置；租户与套餐为多对一。                                                      |
| 租户上下文 | Tenant Context | 一次请求所归属租户的解析结果；无租户上下文的请求不得触碰租户级数据。                                                        |
| 遮蔽语义   | Shadowing      | 租户对某个配置主体存在未删除的自有定义时，该主体消费端整体取租户级数据、平台级定义不再参与合并的覆盖规则（见 ADR-009 D2）。 |

## 权限

| 术语     | 英文               | 定义                                                                                       |
| -------- | ------------------ | ------------------------------------------------------------------------------------------ |
| 功能权限 | Feature Permission | 控制账号能访问哪些菜单与按钮，通过「用户-角色-菜单」关系表达（RBAC）。                     |
| 角色     | Role               | 功能权限与数据权限的载体，分配给用户。                                                     |
| 菜单     | Menu               | 后台导航与功能的权限单元，分三类：目录（分组）、菜单（页面）、按钮（操作点）。             |
| 部门     | Department         | 组织架构树的节点；用户归属部门，数据权限按部门圈定。                                       |
| 数据权限 | Data Scope         | 在功能权限之外，按组织维度限制角色可见数据行的范围。本系统分两档：全部数据、本部门及以下。 |

## 账号与审计

| 术语     | 英文          | 定义                                                                                          |
| -------- | ------------- | --------------------------------------------------------------------------------------------- |
| 会话     | Session       | 登录成功后的服务端在线状态，权威存储在服务端；访问凭证有效但会话不存在即视为已登出。          |
| 登录锁定 | Login Lockout | 连续认证失败达到阈值后临时拒绝该账号登录，防暴力破解。                                        |
| 软删除   | Soft Delete   | 数据行不物理删除，以删除时间标记；常规查询默认排除已删除行。                                  |
| 操作日志 | Operation Log | 管理端写操作的行为审计记录（谁、何时、对什么、做了什么、结果）。                              |
| 登录日志 | Login Log     | 登录成功与失败事件的审计记录（账号、时间、来源、成败原因）；登出事件不记录（见 ADR-009 D5）。 |

## 认证与令牌

| 术语       | 英文               | 定义                                                                                                    |
| ---------- | ------------------ | ------------------------------------------------------------------------------------------------------- |
| 访问令牌   | Access Token       | 短期凭证（2 小时），随请求头发送，用于 API 鉴权。                                                       |
| 刷新令牌   | Refresh Token      | 长期凭证（7 天），HttpOnly Cookie 存储，用于换取新的访问令牌；服务端 Redis 存储支持滑动过期与强制下线。 |
| 多端登录   | Multi-Device Login | 同一账号允许在多个设备同时在线，每设备持有独立会话；管理员可查看并强制下线指定会话。                    |
| 滑动过期   | Sliding Expiration | 每次使用刷新令牌换取新访问令牌时，刷新令牌有效期重新计算。                                              |
| 图形验证码 | Captcha            | 登录连续失败达到阈值后强制要求的人机验证，答案暂存 Redis，有效期 5 分钟。                               |

## 数据组织

| 术语       | 英文              | 定义                                                                                           |
| ---------- | ----------------- | ---------------------------------------------------------------------------------------------- |
| 物化路径   | Materialized Path | 部门树节点的路径字符串（如 `/1/3/5/`），用于快速判定「本部门及以下」的数据范围，避免递归查询。 |
| 权限编码   | Permission Code   | 菜单/按钮对应的唯一权限标识符（如 `system:user:add`），用于 API 级访问控制。                   |
| 平台级数据 | Platform Data     | 不属于任何租户、由平台统一维护的数据（如系统菜单、字典定义）。                                 |
| 租户级数据 | Tenant Data       | 归属于特定租户、可被租户自定义的数据（如参数配置、通知公告）。                                 |

## 系统配置

| 术语     | 英文   | 定义                                                                                                                              |
| -------- | ------ | --------------------------------------------------------------------------------------------------------------------------------- |
| 字典     | Dict   | 以「字典类型 + 字典数据」两级结构集中管理枚举标签（如性别、状态码）的配置机制；平台级标准定义与租户级自定义并存，按遮蔽语义取值。 |
| 参数配置 | Config | 以键值对形式管理系统业务参数（如开关、阈值）的配置机制；平台级默认值与租户级覆盖并存，按遮蔽语义取值。                            |
